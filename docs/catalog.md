# Как подключить каталог

Car Care Assistant поддерживает два независимых сценария. Кнопка «Найти по VIN» запрашивает данные машины. После выбора подтверждённой модификации экран запчастей отправляет артикул или название в каталог. Без шлюза пользователю доступны сохранённые детали и ссылки на внешние источники. VIN не подставляется в ссылки и не отправляется в браузер без действия пользователя.

Сборка с подключением: `flutter build apk --release --dart-define=CATALOG_API_URL=https://example.org/api`. Здесь указывается адрес **вашего** HTTPS-шлюза. Ключи поставщиков, ограничения запросов и маршрутизация по рынкам настраиваются на сервере. Стандартный APK не содержит лицензированных справочников или серверных ключей.

Шлюз принимает JSON POST и отвечает объектом `{"results":[]}`, если совпадений нет.

| Маршрут | Запрос | Поля результата |
| --- | --- | --- |
| `/vin` | `vin`, опционально `market` и `modelYear` | `id` (стабильный ID конкретной модификации; используйте префикс поставщика), `brand`, `model`, `year`, `variant`, `source` |
| `/parts` | `query`, `vehicleId`, `brand`, `model`, `year`, `variant`, опционально `market` | `name`, `brand`, `number`, `oe`, `source`, `vehicleId`, `fitmentConfirmed` |

`market` может быть `EU`, `US`, `CN` или `OTHER`. Значение указывает на первоначальный рынок машины, а не на страну её текущей регистрации. Шлюз должен подтверждать совместимость только при проверенной связи детали с точной модификацией. Одного совпадения OE или названия модели для этого недостаточно. При отсутствии результата приложение может использовать NHTSA vPIC для базовых данных о машине.

## Пилот перед закупкой доступа

Выборка должна включать европейские машины 2000-х, Chevrolet для Северной Америки, китайские машины для внутреннего рынка и их экспортные варианты. Согласуйте с владельцами проверку, держите исходные VIN вне репозитория. Для каждого примера независимо установите модификацию, контрольный OE и, если известен, артикул подходящего аналога.

Заголовок CSV:

```csv
cohort,vin,market,brand,model,year,variant,oe,expected_part
```

Когорты: `EU_2000S`, `CN_DOMESTIC`, `CN_EXPORT`, `GM_NA`. Названия в эталоне должны соответствовать стандартизованным названиям шлюза, а не тексту объявления о продаже. Запустите `python tools/catalog_pilot.py private-sample.csv` с переменной `CATALOG_API_URL`. Отчёт выводит только количества по когортам и не печатает VIN или строки ответов.

Начните с фильтров и планового обслуживания. Для каждого результата с отметкой «подтверждено» отдельно проверьте связи по эталону, включая несколько заведомо неподходящих вариантов. Перед интеграцией уточните у поставщика покрытие рынков, право показать данные в публичном приложении и условия их локального сохранения.
