# Данные в Car Care Assistant

Приложение хранит гараж, историю ТО, расходы и запчасти в базе данных на устройстве. Для обычного использования регистрация не нужна. Резервная копия создаётся по запросу пользователя. Она содержит VIN и записи гаража. Пользователь выбирает место сохранения файла и решает, кому его передавать.

Камера используется для распознавания VIN в штрихкоде. Сканирование выполняется на телефоне. При нажатии «Найти по VIN» номер передаётся в NHTSA vPIC и, если подключён, на шлюз каталога. Запрос деталей в подключённый каталог содержит название или артикул, характеристики выбранной машины и идентификатор модификации, если он есть. Внешний каталог открывается в браузере после нажатия и обрабатывает введённые там данные по собственным правилам.

Контакт по вопросам данных: [репозиторий Car Care Assistant](https://github.com/Mori2282/Car-Care-Assistant). Для публикации в Google Play разместите этот текст по публичному адресу, укажите контакт разработчика и проверьте, что описаны все подключённые сервисы и их фактические сроки хранения.
